# Python Day 6 and Day 7 Notes

Detailed classroom notes in simple Hinglish for Data Science, Machine Learning, Data Preprocessing, NumPy, and Pandas.

## Files

- `index.html` - Browser page with sidebar navigation for Day 6 and Day 7.
- `day6_data_science_machine_learning.md` - Day 6 classroom notes.
- `day7_data_preprocessing_numpy_pandas.md` - Day 7 classroom notes.
- `data/student_scores.csv` - Small local sample dataset for Pandas practice.
- `examples/day7_numpy_pandas_practice.py` - Runnable Day 7 practice code.

## How to Use

Open `index.html` in a browser and switch between Day 6 and Day 7 using the sidebar.

Run example:

```bash
python3 examples/day7_numpy_pandas_practice.py
```
